# BuildMyPC

A parts list and ready-made PC builds. Prices are Canada Computers shelf prices in Canadian dollars, not a live feed. A part that was not on that list keeps its old sample price.

The shop sits behind the offline page. Click the **n** in “connection” three times, then pick a device.

## Run it

```bash
npm install
npm run dev
```

Light and dark are at the top. Languages are at the bottom of the page.
